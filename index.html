Preguntas Frecuentes

Todo lo que necesitas saber

¿Necesito internet para usar el software?

No. El software funciona 100% offline. Solo necesitas internet si quieres enviar presupuestos por WhatsApp.

¿Puedo usar el software en varias computadoras?

Cada licencia es para una computadora. Si necesitas más, ofrecemos descuentos por volumen.

¿Qué incluye el soporte técnico?

Ayuda con instalación, configuración y uso del software. Respondemos en menos de 24 horas.

¿Hay límite de órdenes o clientes?

No. Puedes crear órdenes y clientes ilimitados. La base de datos puede manejar miles sin problemas.

¿Funciona en Windows 7?

Sí. Compatible con Windows 7, 8, 10 y 11. Tanto 32 como 64 bits.

¿Puedo exportar mis datos?

Sí. Todos tus datos están en una base de datos SQLite que puedes respaldar y exportar fácilmente.
