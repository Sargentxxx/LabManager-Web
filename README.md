# LabManager - Sistema de Gestión para Talleres

Landing page oficial de LabManager, un software profesional diseñado para la gestión integral de talleres de reparación de computadoras y dispositivos electrónicos.

## Características Principales

- **Gestión de Órdenes**: Control total de ingresos, procesos y entregas.
- **Inventario**: Seguimiento de repuestos y componentes.
- **Clientes**: Base de datos de clientes con historial de reparaciones.
- **WhatsApp**: Integración para envío de presupuestos y estados.
- **100% Offline**: El software de escritorio funciona sin necesidad de internet.

## Tecnologías Utilizadas

- HTML5 / CSS3 (Diseño Responsivo)
- JavaScript (Vanilla)
- Integración con Pasarelas de Pago:
  - PayPal SDK
  - Mercado Pago SDK
- Firebase (Seguimiento de ventas en tiempo real)
